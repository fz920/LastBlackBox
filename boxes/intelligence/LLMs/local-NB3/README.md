# Retired local NB3 LLM experiment

The Qwen/llama.cpp experiment was removed from this robot because its responses
were slow and too limited for useful interaction. Its downloaded model and runtime
were deleted to recover storage; the previous implementation remains in Git history.

Use the [robot website push-to-talk setup](../../../servers/python/robot_control/README.md#voice-and-text-conversation-openai)
for spoken conversation with OpenAI and camera snapshots. Basic Coral object
narration still works offline, without a language model or API key.
